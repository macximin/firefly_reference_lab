# 리턴 에이스 분석에서 나온 자유 개선안

## 1. 경기판과 시즌판을 한 화면에 겹쳐 본다

야구 장면의 즉시 재미는 이닝·점수·아웃카운트에서 나오지만, 독자가 오래 기다리는 보상은 선발 지위·누적 기록·순위·수상에서 나온다. 회차 편집기 위쪽에 둘을 나란히 둔다.

```text
현재 경기: 7회 말 / 2사 1·3루 / 3-2 리드 / 투구 수 101
이번 장면 약속: 중심 타자 브라이스 하퍼를 막고 텍사스의 리드를 지킨다
시즌 누적: 25승 / 358K / 투수 트리플 크라운 확정
장기 독자 부채: 텍사스 첫 우승 / 네 번째 WS MVP / FA 선택
```

한 타자를 잡은 뒤 경기판은 바로 바꾸고, 시즌판은 공식 본문 결산이 나왔을 때만 확정한다. 장면 속 숫자와 뒤의 시즌 요약이 서로 다른 문제를 줄일 수 있다.

## 2. 한 장면의 ‘보상 환전 경로’를 남긴다

이 작품의 좋은 장면은 보상을 한 번만 주지 않는다. 필 브랫에게 배운 체인지업은 불펜 피칭의 칭찬에서 끝나지 않고 스프링캠프 생존, 개막 로스터, 선발 이닝, 사이영상으로 이어진다. 장면 카드에 다음 연결을 둔다.

```text
훈련 선택 → 현장 성공 → 감독의 운용 변화 → 시즌 기록 → 팀 결산 → 계약·커리어
```

각 칸을 모두 채우라는 뜻은 아니다. 이번 회차가 어느 칸을 지급했고 다음 칸이 무엇인지 보이면 작은 승리가 장편에서 사라지지 않는다.

## 3. ‘선수의 실력’과 ‘감독이 실제로 쓰는 자리’를 분리한다

윤주혁은 타격을 잘한다고 자동으로 지명타자가 되지 않는다. 조 매든이 투수를 타선에 넣고, 루크 다니엘스가 3루 수비까지 맡기고, 데니스 킨이 월드시리즈 구원 시점을 고를 때 능력이 보직으로 바뀐다. 인물 상태에 `available_skills`와 `authorized_roles`를 따로 둔다.

- 던질 수 있음 / 오늘 선발로 예정됨
- 칠 수 있음 / 타순에 들어감
- 3루 수비 가능 / 감독이 실제 기용함
- 불펜 대기 가능 / 의료진·투구 수 조건을 통과함

이 구분은 주인공의 강함을 줄이지 않는다. 감독의 판단과 팀 관계를 승리의 원인으로 살린다.

## 4. 구종은 이름이 아니라 습득 단계로 추적한다

체인지업을 한 번 던졌다고 실전 무기가 완성되는 것은 아니다. 구종 카드에 `그립 이해→불펜 재현→실전 시험→결정구 사용→상대 분석 노출→배합 변주` 단계를 둔다. 스승, 최초 성공 상대, 실투 비용, 최근 사용 패턴도 함께 기록한다.

필 브랫의 체인지업과 애런 루이스의 커브 지도가 뒤의 경기에서 실제로 언제 쓰였는지 되짚을 수 있고, 새 구종이 위기마다 갑자기 생기는 일을 막는다. 상대가 패턴을 읽은 뒤에는 구종 추가보다 같은 공의 속도·코스·순서 변경으로 변주할 수도 있다.

## 5. 동료의 ‘승리 지분’을 회차마다 확인한다

윤주혁이 너무 강해서 동료의 안타·수비·호투가 배경으로 밀릴 위험이 크다. 경기 결산에 `윤주혁의 몫`, `동료의 몫`, `감독·코치의 몫`, `상대가 만든 압력`을 한 줄씩 남긴다.

2012년 월드시리즈의 필립 모리스 결승 스리런, 2015년 텍사스 월드시리즈의 대니 스튜어트 선발 호투는 별도 결산으로 표시할 가치가 있다. 주혁이 MVP를 받더라도 친구와 신인의 몫이 없어지는 것은 아니다. 동료가 직접 지급한 보상이 쌓여야 ‘팀의 첫 우승’이 주인공 개인 기록의 다른 표현으로 마르지 않는다.

## 6. 기록은 ‘장면 합산’과 ‘본문 공식값’을 구분한다

모든 경기 장면이 수록되는 작품이 아니므로 보이는 안타와 탈삼진만 더해 시즌 성적을 만들면 틀린다. 기록 장부에 두 출처를 둔다.

- `scene_observed`: 원고에서 직접 본 경기·타석·투구
- `canonical_summary`: 기사, 중계, 시즌 결산에서 작품이 확정한 숫자

둘이 다르면 누락 경기가 있는지, 오기인지 표시하고 정본은 명시적 시즌 결산을 따른다. 2012년 25승 2패·386탈삼진, 2015년 타격 7관왕 같은 큰 지급은 근거 회차와 함께 잠근다.

## 7. 몸 상태를 패널티가 아니라 ‘가용성 부채’로 본다

부상 경고는 단순히 능력치를 낮추는 장치가 아니다. 고교 혹사 거부는 투수 생명을 사고, 손가락 부상과 수술은 포스트시즌 등판·다음 시즌 준비·계약 평가를 동시에 흔든다. 몸 상태 카드에 다음 네 값을 둔다.

```text
선수 체감 / 의료 판단 / 감독의 사용 한도 / 독자가 기다리는 복귀 조건
```

주혁이 괜찮다고 느껴도 감독이 쉬게 할 수 있고, 한 경기에서 복귀해도 재활 부채는 남을 수 있다. 이 차이를 보이면 부상이 기록 도전 전에 잠깐 긴장만 올리는 장치로 소비되지 않는다.

## 8. 상대의 재분석 기억을 보존한다

강속구·체인지업·타격 경험이 매번 처음 공개되는 것처럼 쓰면 경기 반복이 빨리 보인다. 상대 팀 카드에는 직전 대결에서 본 패턴, 이번에 바꾼 노림수, 성공·실패한 대응을 남긴다.

```text
상대가 아는 것 → 준비한 대응 → 윤주혁이 눈치챈 근거 → 바꾼 선택 → 다음 대결에 남은 정보
```

같은 텍사스라도 2010 ALDS의 벽, 2012 포스트시즌 상대, 2015 소속팀이라는 기능이 다르다. 팀 이름보다 관계와 정보의 변화를 먼저 비교해야 한다.

## 9. 팀 이동 때 ‘새 팀 적응표’를 자동으로 연다

트레이드는 유니폼만 바꾸지 않는다. 리그 규칙, 홈구장, 감독 철학, 포수, 선발 순번, 타순, 수비 위치, 동료의 기대, 친정팀 관계가 한꺼번에 움직인다. 탬파베이→워싱턴→텍사스→시카고 전환마다 다음 표를 새로 만든다.

| 항목 | 이전 팀 | 새 팀 | 첫 검증 경기 | 적응 완료 근거 |
| --- | --- | --- | --- | --- |
| 투수 보직 |  |  |  |  |
| 타격·수비 역할 |  |  |  |  |
| 감독의 신뢰 방식 |  |  |  |  |
| 핵심 동료 |  |  |  |  |
| 장기 팀 약속 |  |  |  |  |

2013년의 개인 트리플 크라운과 팀 탈락, 2014년의 워싱턴 첫 우승을 같은 ‘워싱턴 구간’으로 뭉개지 않고 적응과 팀 결산의 차이로 읽을 수 있다.

## 10. 관계 장면에도 시즌 기능을 붙인다

한유라와 부모의 장면은 경기 사이 휴식으로만 분류하면 장기 감정선이 끊긴다. 관계 카드에 `몸의 부담을 누구에게 말했는가`, `다음 경기를 대하는 태도가 어떻게 달라졌는가`, `은퇴 뒤 삶에 무엇이 생겼는가`를 기록한다.

필립 모리스와의 우정은 첫 생의 상실을 바꾸고, 한유라와의 결혼은 명예의 전당 뒤 홀로 남았던 삶을 바꾼다. 관계 보상은 경기 기록과 경쟁하지 않는다. 주혁이 무엇을 위해 몸을 지키고 어느 팀을 고를지 결정하는 시즌 자원이다.

## 11. 대형 결산에는 네 사람의 반응을 강제로 대조한다

우승·신기록·MVP 장면은 숫자가 너무 커서 비슷하게 보이기 쉽다. 대형 결산마다 최소 네 시점을 후보로 띄운다.

1. 윤주혁 본인: 첫 생의 어떤 미련이 닫혔는가
2. 핵심 동료 또는 감독: 자기 선택과 노력이 어떻게 인정됐는가
3. 패한 상대: 어떤 대응까지 했으나 무엇이 모자랐는가
4. 가족·팬·시장: 기록이 관계와 계약 가치로 어떻게 번졌는가

모두를 원고에 넣을 필요는 없다. 직전 결산에서 쓴 반응과 겹치지 않는 두세 개를 고르면 신인왕, 사이영상, 월드시리즈 MVP가 같은 환호 장면으로 반복되는 일을 줄일 수 있다.

## 12. 310화 내부를 별도 장면 타임라인으로 감리한다

마지막 표식 하나에는 텍사스 우승 여진, 한유라와의 결혼, 스캇 조나스의 FA 협상, 시카고 계약, 2016년 정규 시즌과 월드시리즈 7차전이 들어 있다. 회차 지도는 310화 하나로 보존하되 내부에는 다음 구획을 둔다.

```text
2015 텍사스 결산
→ 결혼과 귀국
→ 10년 5억 2천만 달러 계약
→ 2016 컵스 시즌 압축
→ 클리블랜드와 7차전 마지막 아웃
→ 베이브 루스를 넘는 다음 목표
```

시간 점프, 팀, 관계, 커리어 상태가 한 문단 사이에서 바뀔 때 체크포인트를 저장한다. 이어쓰기가 텍사스 소속인 주혁과 컵스 소속인 주혁을 섞거나, 결혼 전 관계로 되돌아가는 오류를 막는다.

## 13. 자연 Arc와 1~3화 제작 Packet을 함께 비교한다

한 경기나 포스트시즌 시리즈는 4화 이상 이어질 수 있다. 창작 화면에는 자연 Arc의 전체 질문과 지금 쓰는 1~3화 Packet의 작은 질문을 동시에 보인다.

```text
자연 Arc: 텍사스가 워싱턴을 꺾고 창단 첫 우승을 얻는가
현재 Packet: 대니 스튜어트가 4차전 초반을 버티는가
이번 화 지급: 위기를 최소 실점으로 넘기고 주혁의 후반 투입 조건을 만든다
아직 미지급: 마지막 아웃 / 팀 첫 우승 / WS MVP / 친정 동료와의 여진
```

제작 단위가 짧아도 상위 결산을 잃지 않고, 반대로 우승 약속 때문에 매 화가 결승 장면처럼 과열되는 것도 막을 수 있다.

이 개선안의 기준은 하나다. 윤주혁이 무엇을 해냈는지만 기록하지 않고, 그 선택이 누구의 판단과 도움을 거쳐 한 경기에서 지급되고 시즌·관계·커리어에 무엇을 남겼는지 추적한다.
