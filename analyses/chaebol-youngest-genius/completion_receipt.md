## 2. 회차 데이터 실제 수량

현재 최종 병합 전 분할 파일을 직접 파싱한 결과다.

| 분할 | chapter_map | arc_pacing | 임시 Arc ID |
|---|---:|---:|---:|
| 001–095 | 95행 | 95행 | A01–A19, 19개 |
| 096–190 | 95행 | 95행 | B01–B19, 19개 |
| 191–285 | 95행 | 95행 | C01–C15, 15개 |

| **합계** | **380행** | **380행** | **병합 전 69개** |

검사 결과는 다음과 같다.

- `chapter_map` 네 파일은 계약의 19열 헤더와 일치하고, 데이터 행은 정확히 380개다.
- `arc_pacing` 네 파일은 계약의 14열 헤더와 일치하고, 데이터 행은 정확히 380개다.
- 두 계열 모두 `sequence` 1–380이 연속이며 중복·누락이 없다.
- `chapter_map` 원문 행 경계는 1–89,897이 끊김 없이 이어진다.
- 모든 행에 임시 `arc_id`가 있고, 같은 회차의 `chapter_map`과 `arc_pacing` 사이 Arc ID 불일치는 0건이다.
- 페이싱 수치 필드는 모두 1–10 범위 안에 있다.

이 수량은 분할 원본의 현재 사실이다. 최종 `chapter_map.csv`와 `arc_pacing.csv`를 생성한 뒤에도 각각 데이터 380행이어야 하며, 헤더를 행 수에 포함하면 안 된다.

## 3. Arc 후보 수와 경계 불확실성

분할 메모의 로컬 ID를 그대로 세면 Arc 후보는 69개다. 다만 분할선 때문에 잘린 것이 명백한 두 쌍을 각각 하나로 병합하면 현재의 전역 후보 기준값은 **67개**다.

1. **A19/B01**: A19의 93–95화는 허상도가 5공 청문회에서 외환관리법 위반을 자백하는 중간에 끝난다. B01의 96–100화는 1,000억 원 국고 귀속, 허상도·김 실장 체포, 사면 좌절과 생모 사고까지 바로 지급한다. 두 로컬 ID는 하나의 청문회·속죄 Arc로 합치는 편이 강하다.
2. **C15/D01**: C15의 285화는 항저우에서 마윈을 만나 `선악의 저울`을 여는 순간 끝나며 투자 조건이 없다. D01의 286–293화가 차이나 옐로 페이지 49% 투자와 중국 물류 교두보를 지급한다. 둘은 하나의 마윈·알리바바 선점 Arc로 보아야 한다.
3. **C01의 앞 경계**: C01 191–193화의 `김장독` 기습 출시와 진성의 패배는 175–184화 B17에서 설계·제작한 반간계의 지연 지급이다. 그러나 사이에 B18의 인력 보상과 B19의 이철근 응징이 끼어 있어, C01을 B17에 비연속적으로 흡수할지 `출시·재계 인정`의 독립 결산 Arc로 유지할지는 최종 Atlas에서 명시해야 한다. 이 선택에 따라 전역 Arc 수는 67개를 유지하거나 66개로 조정될 수 있다.

따라서 이 초안은 `69개 로컬 후보 → 명백한 분할 병합 후 67개 전역 후보`, `C01 처리에 따라 66–67개 가능`이라고 기록한다. 최종 `arc_map.csv`의 Arc 수와 `arc_atlas.md`의 목차 수가 결정되면 이 숫자를 반드시 하나로 고쳐야 한다.

## 4. 작품 계약에 대한 자체 반례 검사

### 반례 A · “허준수는 혼자 다 알고 매번 같은 방식으로 이긴다”는 요약은 성립하지 않는다

- 103–104화에서 어린 몸의 허준수는 한남철과의 체격 차 때문에 실제 치명타 위험에 놓이고 장우혁의 개입이 필요하다. 무술 능력은 무조건 승리가 아니라 신체 한계와 경호 인재 획득으로 지급된다.
- 135–147화 마산 선거에서 강철중은 조성래의 불법 자료 사용을 거부한다. 준수는 미래 지식과 조사력을 갖고도 타인의 윤리적 선택을 통제하지 못한다.
- 185–187화 스칼릿은 성인잡지·영화 카드를 지렛대로 비서직을 얻는다. 준수는 관계 협상에서 일방적으로 이기지 않으며, 더 영리한 동료를 받아들인다.
- 283화 스티브 영은 준수의 버튼식 스마트폰 시안을 거부하고 터치스크린 중심의 재개발을 요구한다. 준수는 자기 누락을 인정하고 출시를 늦추며 전권을 준다. 만능성의 보상은 정답 독점이 아니라 전문가를 고르고 반론을 수용하는 조직 능력으로 바뀐다.
- 후반 아프리카 사업에서도 마윈, 로버트, 마이클, 장우혁, 현지 학생·정부·군대가 실행 주체가 된다. 준수의 선견지명만으로 결과가 자동 발생하지 않는다.

### 반례 B · “성공은 모두 무비용으로 지급된다”는 요약도 성립하지 않는다

- 5공 비자금 1,000억 원을 국고에 돌려도 허상도와 김 실장은 체포되고 사면은 1993년까지 막힌다. 도덕적 인정은 자유의 지연이라는 비용을 없애지 않는다.
- 검은 수요일 베팅은 5억 달러와 자산 25%의 손실 가능성을 걸고, LA 폭동 방어는 총격·방화 노출과 1억5천만 달러 피해를 동반한다.
- 세계통신 인수 1,000억 원, 이동통신 낙찰 5,500억 원, 반도체 10조 원, 하버드 기부 1억 달러처럼 미래 지식은 실제 자본을 묶는다. 결과를 안다는 설정이 현금·유동성·기회비용을 지우지 않는다.
- 복제양 둘리 Arc는 연구수익 25% 재투자, 조기 제왕절개, 총기 위협, 생명윤리 논쟁과 화이자의 적대를 남긴다.
- 삼풍 인수에는 1,500억 원 추가 지급과 가족 테러가 붙고, 스티브 영 영입에는 준수 보유지분 20%와 통제권을 나누는 비용이 붙는다.
- 탄자니아·르완다 구간에서는 이미 투입한 철도·항만·학교 50억 달러가 인질이 되고, 시위 유혈·난민·장우혁과 용병의 생명·국제 분쟁 위험이 남는다. 후반의 국가급 인정은 개인적·정치적·군사적 잔여 비용 위에서 지급된다.

이 반례들은 `능력 개방 → 사용 → 즉시 성공`만으로 작품을 평면화하면 안 된다는 자체 점검 장치다. 최종 Bible과 Atlas에서도 적어도 초반·중반·후반 각 한 사례 이상을 비용·대리인·관계 제한과 함께 남겨야 한다.

## 5. InkOS 읽기 전용 확인 영수증

현재 InkOS 작업 트리는 수정하지 않고 읽기와 선택 테스트만 수행했다. Arc·Forecast·Rail 및 관련 Studio 표면을 대상으로 **Core 86개 + Studio 15개 = 총 101개 테스트가 모두 통과**했다.

이 결과의 범위는 분명히 제한한다.

- 확인됨: 관련 Core와 Studio 선택 테스트 101개 통과.
- 확인되지 않음: InkOS 전체 빌드, 전체 테스트 스위트, 브라우저 수동 조작, 실제 장편 380회 Import·운영 리허설.
- 따라서 `101 tests pass`는 현재 보고서의 구조 제안이 기존 코드 표면과 충돌하지 않는다는 부분 증거이지, InkOS 전체 제품의 무결성 보증은 아니다.

## 7. 최종 strict 전 남은 검사

- 최종 `project_bible.md`와 `arc_atlas.md`가 생성된 뒤 1–380화의 결말, 주요 인물, 능력, 장소, 조직, 비용과 보상 표면을 분할 메모와 교차 확인한다.
- `arc_map.csv`의 Arc 수를 확정하고, 모든 Arc에 최소 두 개의 경계 신호, 실제 사건형 이름, 인물·장소, 관계 변화, 잔여 비용과 다음 훅이 있는지 검사한다.
- 최종 `chapter_map.csv`와 `arc_pacing.csv`가 각각 데이터 380행인지, `sequence` 1–380이 연속인지, Arc ID가 `arc_map.csv`·`arc_atlas.md`와 일치하는지 다시 파싱한다.
- A19/B01과 C15/D01 병합을 반영하고 C01의 앞 경계를 확정한 뒤, 이 문서의 66–67개 잠정 표기를 단일 최종 수치로 바꾼다.
- 네 Goal 파일이 모두 충분한 해상도로 존재하는지, 초반·중반·후반 근거와 결말 Arc의 수렴이 빠지지 않았는지 확인한다.
- strict 검사 결과와 실제 실행 명령·성공 여부를 최종 영수증에 추가한다.

현재 단계에서 확정할 수 있는 결론은 원문 SHA·표식 380개, `chapter_map` 380행, `arc_pacing` 380행, 회차 1–380 전수 범위, 분할 기준 Arc 후보 69개, 관련 InkOS 선택 테스트 101개 통과까지다. 전역 Arc 수와 네 Goal의 최종 승인은 아직 유예한다.
