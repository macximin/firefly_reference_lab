## 제작 가설

기업회생 회계사 윤태겸은 첫 생에서 해원그룹의 분식회계 책임을 뒤집어쓰고 아버지의 공장까지 잃었다. 12년 전 첫 현장 실사로 돌아온 그는 망할 회사를 피하지 않는다. 장부, 계약, 설비에서 돈이 새는 경로를 찾아 회사를 살리고, 수수료 대신 지분과 의결권을 받는다.

태겸은 오너 일가 밖에서 시작해, 남들이 버린 회사의 월급날을 지키면서 자기 소유를 늘린다.
