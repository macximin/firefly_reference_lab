# 재벌물 Reference Core · 작품별 Binding Recipes

## 기본 정책

- 작품별 opt-in이다. 공용 코어 설치만으로 어떤 작품에도 적용하지 않는다.
- 시작 묶음은 `운영 정체성 1 + 현재 사건 1 + 보상 1`이다.
- 최대치를 채우기 위해 카드를 연결하지 않는다.
- 같은 자료도 작품마다 `uses`와 `note`를 다르게 쓴다.
- 문체는 별도 `style_guide.md`와 `style_profile.json`에서 관리한다.
- candidate-only 자료는 production binding에 넣지 않는다.
- 승인 골드 하나를 주축 골격으로 지정하고, 나머지는 사건·보상 은행으로 쓴다.
- 업종·사건 순서·보상 구조의 유사성을 피하려고 표면을 억지로 바꾸지 않는다.

## Recipe A · 미래 베팅형 그룹 구원자

### 적합한 약속

다가올 경제 변곡점을 먼저 알고 자기 자본과 그룹 생존권으로 바꾸는 작품.

### 카드 조합

- `CHB-CORE-01`: 역사 베팅형 투자자·그룹 구원자
- `CHB-CORE-02`: 작은 미래정보 검증과 첫 실제 돈
- `CHB-CORE-03`: 정보→사람·거래→소유권 환전
- `CHB-CORE-05`: 돈·지분·가족 인정의 분리 지급
- 필요할 때 `CHB-CORE-06`: 개인 자본에서 산업으로 넘어가는 자격과 공개 점수판

### 바인딩 메모 예시

`주축 골드의 경제 변곡점 선점→작은 검증→실제 현금→의사결정권 상승을 유지한다. 실제 역사 사건과 기업은 사실 검증하고, 원문 문장·고유 대사·허구 고유명만 직접 전사하지 않는다.`

## Recipe B · 부실계열사 회생형 후계자

### 적합한 약속

망가진 회사에서 회수 가능한 가치와 책임질 사람을 찾아 자기 지분·권한으로 남기는 작품.

### 카드 조합

- `CHB-CORE-01`: 부실계열사 회생형 후계자
- `CHB-CORE-03`: 물증·실행자·협상·가동의 사건 엔진
- `CHB-CORE-04`: 현장·법률 실행자의 독립 판단과 합법적 반대자
- `CHB-CORE-05`: 급여·재가동·지분·표의 통화 교체
- 필요할 때 `CHB-CORE-06`: 회수액·부족액·남은 시간 점수판

### 바인딩 메모 예시

`주축 골드의 숨은 재고·장부 확인→현장 저항→협상→재가동→지분 보상 골격을 유지한다. 현재 캐논과 충돌하는 담당 인물과 물증만 냉동물류 조건에 맞춘다.`

## Recipe C · 기술가치 창출형 실무자

### 적합한 약속

현장의 결함이나 기술 가능성을 발견하고 제품·특허·생산권·회사로 키우는 작품.

### 카드 조합

- `CHB-CORE-01`: 기술가치 창출형 실무자
- `CHB-CORE-03`: 결함→도면·시제품·성능표→계약 환전
- `CHB-CORE-04`: 연구·생산·법무 실행자의 별도 판단
- `CHB-CORE-05`: 로열티·지분·직책·기여자 배분

### 주의

이 조합은 production core의 일반 계약만 사용한다. 《연봉 1조 신입사원》의 상세 기술 상업화 기능은 candidate-only이므로 Gold 승격 전에는 구체 사건·보상 근거로 쓰지 않는다.

## Recipe D · 계열사 미션 해결형 오너

### 적합한 약속

평판이 낮거나 인정받지 못한 오너 일가 주인공이 계열사 문제를 해결하면서 가족 신뢰와 조직 권한을 얻는 작품.

### 카드 조합

- `CHB-CORE-01`: 계열사 미션 해결형 오너
- `CHB-CORE-02`: 무시→작은 검증→첫 자리·호칭 변화
- `CHB-CORE-04`: 실무진의 거부와 주인공의 권한 배분
- `CHB-CORE-05`: 기업 성과와 가족 관계를 서로 다른 영수증으로 지급

### 주의

가족 신뢰도 수치나 시스템 과제는 공용 필수 장치가 아니다. 가족은 감탄보다 예산·직책·후속 의뢰·공동 책임으로 태도를 바꾼다.

## Recipe E · 산업 건설형 창업가

### 적합한 약속

제품 하나를 공장·유통망·플랫폼·공급망으로 연결해 새 산업의 규칙을 만드는 작품.

### 카드 조합

- `CHB-CORE-01`: 산업 건설형 창업가
- `CHB-CORE-03`: 한 제품의 생산·판매·회수 구조
- `CHB-CORE-04`: 기술자·생산자·판매자의 독립 몫
- `CHB-CORE-05`: 제품 성능, 주문, 지분, 조직 보상
- `CHB-CORE-06`: 이전 자산이 다음 산업 진입 자격이 되는 인과 사다리

### 주의

국가와 세계 규모는 필수가 아니다. Series Contract의 종착점이 국내 산업·지역 고용·특정 시장 1위라면 거기서 닫는다.

## InkOS 등록과 연결 예시

1. 필요한 `materials/*.md`를 각각 `ingest_material`로 보관한다.
2. 반환된 정확한 `materialId`를 기록한다.
3. 활성 작품에서 `manage_book_reference`를 호출한다.

```json
{
  "action": "bind",
  "materialId": "<ingest_material이 반환한 ID>",
  "uses": [
    "부실기업 회생 사건의 물증과 계약 결산",
    "첫 지분이 다음 Arc의 의결권으로 남는 구조"
  ],
  "note": "현재 작품 캐논과 Series Contract가 우선이다. 업종·사건 순서·보상 구조는 유지할 수 있고, 원문 문장·고유 대사·허구 고유명만 직접 전사하지 않는다."
}
```

연결은 자료를 복사하거나 캐논을 수정하지 않는다. 해제할 때도 프로젝트 자료는 보존된다.

## 회차 투입 전 점검

- 이번 회차 목표와 직접 관련된 카드인가?
- 카드가 주인공의 경제 동사를 선명하게 하는가?
- 주축 골드의 업종·사건열·보상 리듬이 불필요하게 해체되지 않았는가?
- 지급할 보상과 목격자가 구체적인가?
- 캐논과 충돌하는 부분만 필요한 만큼 정합화했는가?
- 문체 지시를 Reference Core에 섞지 않았는가?
