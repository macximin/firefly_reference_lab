# CHB-CORE-06 · 스케일·점수판·다음 압력

## 목적

개인 승리를 회사·산업·국가 규모로 키울 때 원인 사다리를 보존하고, 각 단계의 현재 상태와 다음 압력을 독자가 즉시 읽게 한다. 같은 인수와 감탄의 반복도 막는다.

## 입력 조건

- 현재 주인공이 실제로 소유하거나 통제하는 자산
- 다음 산업에 들어갈 인과적 자격
- 이번 Arc에서 공개할 점수와 아직 미정인 판정
- 최근 세 Arc의 보상 통화·상대·장소·물증
- 커질 필요가 없는 영역과 작품의 최종 규모

## 재사용 판단

스케일은 크기가 아니라 선택권의 연쇄로 올린다.

`개인 자본 → 첫 소유권 → 실행 조직 → 계열·산업 연결 → 시장 규칙에 영향 → 필요한 경우 공공·국가 협상`

각 화와 Arc에는 현재 점수와 다음 압력을 분리한다.

- 현재 점수: 이번 화에서 확정된 돈, 가동, 표, 계약, 사람의 선택
- 미정 판정: 아직 서명되지 않은 계약, 남은 표, 만기, 경쟁자의 대응
- 다음 압력: 더 큰 자산이 아니라 현재 보상을 지키기 위해 해결해야 할 구체 조건

## 장면 표면

- `회수액 / 부족액 / 남은 시간`, `확보 지분 / 필요한 표`, `생산량 / 불량률 / 납기`처럼 업종에 맞는 2~3개 숫자
- 회의실 칠판, 공장 모니터, 공시, 주문 현황, 이사회 표결처럼 인물이 보는 점수판
- Arc 종료 직후 도착하는 증자 공문, 납품 중단, 경쟁 입찰, 감사 통보, 신규 규제
- 새 산업 진입을 가능하게 한 이전 Arc의 사람·기술·현금·유통망

점수판은 장면을 대신하는 보고서가 아니다. 숫자를 바꾸기 위해 누가 무엇을 했고 누가 거부했는지가 먼저다.

## 출력 계약

NarrativeArc 종료 시 다음을 확인한다.

1. 이전에 없던 선택권이 무엇인가?
2. 그 선택권이 다음 산업 진입에 왜 필요한가?
3. 현재 결산을 독자가 어떤 표면으로 확인했는가?
4. 아직 미정인 판정과 다음 상대는 무엇인가?
5. 최근 Arc와 보상·물증·장소·인정 주체가 어떻게 다른가?

## 실패 신호

- 개인 투자 성공 다음 화에 인과 없이 국가사업을 지휘한다.
- 새 산업은 이름만 바뀌고 사건 문법과 보상이 같다.
- 숫자판이 인물 행동과 저항을 요약해 버린다.
- 훅을 위해 이번 화의 실제 지급까지 숨긴다.
- 작품의 독자 약속과 무관하게 세계 제국·외교·전쟁으로 커진다.

## 직접 전사 금지

- 원문의 문장과 고유 대사
- 허구의 인물·회사 고유명
- 긴 결산·전환 장면 묘사의 문장 단위 전사

승인 골드의 산업·역사·국가 사건 배열, 팀 이동·시즌·기록 사다리, 공시 숫자대와 계약 보상은 라우팅할 수 있다. 실제 기업·정부와의 거래는 별도 사실 검증을 거친다.
