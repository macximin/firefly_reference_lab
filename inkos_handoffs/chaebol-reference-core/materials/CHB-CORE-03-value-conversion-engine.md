# CHB-CORE-03 · 가치 환전 사건 엔진

## 목적

미래정보·능력·업종 지식을 설명으로 소비하지 않고, 사람과 물증과 거래를 거쳐 주인공의 실제 자산으로 환전한다.

## 입력 조건

- 이번 Arc의 저평가 대상: 사람, 기술, 재고, 기업, 사업권 중 하나
- 현재 소유자와 의사결정자
- 숨은 가치를 입증할 업종별 물증
- 실행에 필요한 전문가와 자금
- 상대가 거부하거나 역이용할 수단
- 결산 뒤 주인공에게 남을 소유권 또는 선택권

## 재사용 판단

기본 사건 문법은 다음과 같다.

`이상 징후 발견 → 가설 → 물증 교차 확인 → 실행자 배치 → 상대의 저항 → 가격·책임·권리 협상 → 서명·입금·가동 → 소유 상태 갱신`

정보가 맞다는 사실과 주인공이 돈을 번다는 사실 사이에 최소 하나의 실행 장벽을 둔다. 장벽은 법률, 시간, 생산, 현금흐름, 사람의 동의, 공개 검증 중 현재 업종에 맞게 고른다.

## 장면 표면

업종마다 “무엇이 사실을 증명하는가”를 먼저 정한다.

| 업종 문제 | 가능한 물증 | 거래 결과 |
| --- | --- | --- |
| 제조·회생 | 재고, 전력, 부품번호, 불량률, 납품서 | 가동권, 우선주, 생산계약 |
| 기술·제품 | 도면, 시제품, 성능표, 특허 선행기술 | 특허, 로열티, 독점 생산권 |
| 금융·투자 | 현금흐름, 담보, 포지션, 만기, 공시 | 지분, 채권, 유동성, 의결권 |
| 유통·플랫폼 | 주문, 반품, 물류시간, 결제 데이터 | 채널, 수수료, 사용자망 |
| 부동산·개발 | 소유권, 용도, 인허가, 동선, 임차 | 토지, 운영권, 우선협상권 |

표는 사실 연구를 대신하지 않는다. 실제 신작은 선택 업종의 시장 자료와 전문가 검증을 별도로 붙인다.

## 출력 계약

NarrativeArc와 Chapter Packet에 다음을 적는다.

- 발견한 가치와 최초 소유자
- 독자가 화면에서 볼 물증 1~3개
- 실행자의 독립 판단
- 상대의 유효한 거부 수단
- 지급될 돈·권리·지위
- 다음 Arc에서도 재사용 가능한 누적 자산

## 실패 신호

- `저평가 발견 → 바로 인수 → 모두 감탄`으로 끝난다.
- 주인공의 설명이 물증과 전문가 판단을 대신한다.
- 상대는 가격도 권한도 지키려 하지 않는다.
- 계약은 했지만 무엇을 소유하고 누가 결정권을 잃었는지 불명확하다.
- 업종만 바뀌고 같은 비리 장부·숨은 재고를 반복한다.

## 직접 전사 금지

- 원문의 문장, 고유 대사와 긴 장면 묘사
- 허구의 인물·회사 고유명
- 실존 기업 사건을 사실 조사 없이 사용하는 행위

승인 골드의 공장·특허·유전·은행·역사 사건 순서, 금액대, 지분과 계약 보상은 라우팅할 수 있다. 실존 사건은 원작과 다르게 보이게 만드는 것보다 사실 검증을 우선한다.
