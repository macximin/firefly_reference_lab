# 재벌물 Reference Core · candidate-only 확장 후보

## 사용 경계

이 문서는 승인 전 탐색 목록이다. 아래 작품은 `project_pitch.md`에서 반복 재미와 보상 기능을 확인했지만, 관리자 QA를 통과한 Gold Reference Card가 없다. 따라서 production Gold Router 입력 금지다.

후보 기능은 새 카드의 가설을 세우거나 다음 관리자 재분석 우선순위를 정하는 데만 쓴다. 업종·사건열·보상 장면을 라우팅하지 않는 이유는 유사성 회피가 아니라 분석 완전성과 관리자 승인이 아직 부족하기 때문이다.

## 우선 승격 제안

현재 production core의 가장 큰 빈칸은 다음 세 가지다.

1. 기술·제품의 단계적 상업화: 《연봉 1조 신입사원》 후보
2. 가족 신뢰와 기여자 배분: 《금수저생활백서》 후보
3. 능력·제품·조직·사회 문제 해결의 스케일 전환: 《마법 배운 재벌집 늦둥이》 후보

다음 Gold는 작품 수를 늘리기 위해 고르지 않는다. 실제 신작에서 production-ready 카드로 해결되지 않는 문제가 반복될 때 해당 슬롯의 원문 전수 분석을 재개한다.

## 후보 카드 승격 게이트

- 원문 전 범위와 제공 종료 상태가 명확하다.
- 자연 NarrativeArc 전수가 실제 사건 경계와 맞는다.
- strict 오류 0·경고 0이다.
- 관리자 수동 QA 15/15를 통과한다.
- `gold_reference_card.md`에 best_at, 직접 라우팅 가능 자산, 역할별 사용, 직접 전사 금지, Anti-Gold가 있다.
- 기존 6개 카드와 다른 생산 기능을 제공한다.
