# 한국 재벌 웹소설 Reference Core v1

## 목적

이 폴더는 여러 재벌물 신작이 함께 쓸 수 있는 업종·사건열·보상 장면을 InkOS의 작품별 레퍼런스로 전달한다. 승인 골드 하나를 주축 골격으로 삼고 다른 골드의 사건·압박·반전·보상을 보조 은행으로 붙인다. 구조 유사성은 결함이 아니며, 원문의 문장·고유 대사·허구 고유명과 긴 장면 묘사만 직접 전사하지 않는다.

## 현재 승인 범위

- production-ready 근거: 관리자 QA 15/15와 strict PASS를 모두 받은 《독식하는 재벌 3세》, 《리턴 에이스》
- candidate-only 근거: 작품 피치는 있으나 Gold 승격 전인 재벌·기업물 7편
- 공용 카드 수: 6개
- 연결 정책: 작품별 opt-in. 모든 작품에 자동 연결하지 않는다.
- 원문 사용: 없음. 카드에는 원문 문장을 싣지 않지만 검증된 업종·사건 순서·보상 문법은 라우팅 대상으로 기록한다.

`manifest.json`이 카드 목록과 승인 근거의 기계 판독 정본이다. 후보 작품은 `candidate-expansion-index.md`에서만 관리하며 production Gold Router 입력으로 사용하지 않는다.

## 카드

| ID | 기능 | 기본 역할 |
| --- | --- | --- |
| `CHB-CORE-01` | 주인공의 경제 운영 정체성 | Spine, Engine |
| `CHB-CORE-02` | 바닥·자원·작은 증명·첫 돈의 Entry | Engine, Payoff |
| `CHB-CORE-03` | 정보·기술·문제를 계약과 소유로 바꾸는 사건 엔진 | Engine, Spine |
| `CHB-CORE-04` | 실행자, 반대자, 시한과 독립 판단 | Engine, Emotion |
| `CHB-CORE-05` | 돈·권리·지위·관계의 보상 영수증 | Payoff, Emotion |
| `CHB-CORE-06` | 공개 점수판, 스케일 전환, 다음 압력과 피로 방지 | Hook, Spine, Wildcard |

## 작품별 사용 순서

1. 승인 골드 하나를 주축으로 고르고 주업종·반복 동사·초반 진입·보상 리듬·성장 사다리를 잠근다.
2. Series Contract에서 주인공의 출발 신분과 첫 자산을 주축 골격에 맞춘다.
3. 다른 승인 골드에서 현재 필요한 사건·압박·반전·보상 장면을 고른다.
4. `CHB-CORE-01`~`06`은 주축을 해체하는 추상화 도구가 아니라 빠진 연결부를 점검하는 보조 카드로 쓴다.
5. 업종·사건 순서·보상 구조는 비슷하다는 이유로 바꾸지 않고, 캐논과 충돌하는 원인·담당 인물만 정합화한다.
6. 실제 원고 뒤 Reward Receipt로 효용과 부작용을 확인하고 다음 미작성 계획만 바꾼다.

권장 시작 묶음은 `운영 정체성 1 + 사건 엔진 1 + 보상 1`이다. 슬롯을 채우기 위해 카드를 늘리지 않는다.

## InkOS 연결

각 `materials/*.md`는 InkOS `ingest_material`로 개별 보관할 수 있는 파일이다. 보관 뒤 `manage_book_reference`로 특정 작품에 연결한다.

현재 InkOS 프로젝트의 공용 자료함에 6개 카드를 중복 없이 설치하려면 다음을 실행한다. 설치기는 같은 원본 경로의 기존 자료를 재사용하며 작품 바인딩은 바꾸지 않는다.

```text
node tools/install-chaebol-reference-core.mjs
```

- `uses`: 현재 작품에서 맡길 자연어 용도. 예: `부실기업 회생 사건의 물증과 계약 결산`, `첫 5화의 돈·지위·관계 보상`
- `note`: 사용 제한. 예: `회생업 골격과 장부→협상→재가동→지분 보상을 유지한다. 원문 문장·고유 대사·허구 회사명만 직접 옮기지 않는다.`
- 연결 결과: `books/<book_id>/story/reference_bindings.json`
- 선택 시점: 회차 목표·아웃라인·mustKeep에 따라 필요한 카드 구간만 Composer 컨텍스트에 들어간다.

자료 보관과 작품 연결은 별개다. 공용 코어를 설치해도 어떤 작품에도 자동 적용되지 않는다. 같은 카드를 여러 작품에 서로 다른 `uses`와 `note`로 연결할 수 있다.

## 문체 경계

문체는 이 Reference Core에 포함하지 않는다. 사건·보상 레퍼런스와 문체 모사는 다른 위험과 다른 검수가 필요하다.

- 이 코어: 무엇을 판단하고 어떤 결과를 장면으로 지급할지
- `story/style_guide.md`: 현재 작품이 어떤 서술 거리·리듬·대사·장면 밀도로 쓸지
- `story/style_profile.json`: 선택한 참고 원고의 통계적 문체 지문

신작의 문체 설정은 별도로 만들고 Writer가 읽게 한다. 특정 원작의 문장, 비유, 대사 습관을 이 카드에 넣지 않는다.

## 권위와 금지선

권위는 `사용자 의도·작품 캐논 → Series Contract → 현재 NarrativeArc → 선택된 Reference Core 카드 → 일반 장르 지식` 순이다.

- 레퍼런스는 캐논을 자동 변경하지 않는다.
- 원문의 문장, 고유 대사, 허구 인물·회사명과 긴 장면 묘사를 직접 전사하지 않는다.
- 같은 업종, 사건 유형과 순서, 보상 구조, 관계 변화 문법은 라우팅할 수 있으며 유사성을 이유로 감점하지 않는다.
- 실제 역사 사건과 기업을 사용할 때는 원작과의 거리보다 사실 검증을 우선한다.
- candidate-only 작품을 production-ready로 표시하지 않는다.
- 돈의 증가만으로 보상 완료를 선언하지 않는다.
- 모든 재벌물을 국가·세계 규모로 키우지 않는다.
- 같은 카드 조합을 모든 작품에 반복하지 않는다.
