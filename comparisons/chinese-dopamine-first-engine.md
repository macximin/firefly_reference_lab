# 중국식 도파민 퍼스트 엔진: InkOS 비교 가설

기존 내부 보고서의 ‘판결 엔진’을, 한국 웹소설 원문 코퍼스와 내 작품을 비교하기 위한 가설로만 등록한다. 이 문서는 특정 작품의 문장·장면을 재현하거나 모사하는 규칙이 아니다.

## 비교할 추상 축

| 축 | 관찰 질문 | InkOS Arc 적용 형태 |
| --- | --- | --- |
| 독자 선인지 | 독자가 인물보다 먼저 아는 우위/위험은 무엇인가? | Arc의 `promise`, `mustKeep` |
| 판정 질문 | 이번 1~3화에 결론 날 작고 구체적인 질문은 무엇인가? | `goal`, `payoff` |
| 증거 상태 | 주장을 행동·물건·문서·선택 중 무엇으로 검증하는가? | `turn`, `irreversibleChange` |
| 압박 상승 | 다음 블록에서 장소·관계·손실 중 무엇이 커지는가? | `pressure`, 다음 Arc 훅 |
| 보상 유예 | 지금 지급할 소보상과 나중에 남길 대보상은 무엇인가? | `payoff`, `nextHook` |
| 관계 결산 | 외적 승리 뒤 어떤 관계 상태가 바뀌는가? | `relationshipChanges` |

## 검증 규칙

1. 각 가설은 한국 원문 코퍼스 또는 내 작품에서 최소 2개 독립 근거를 찾기 전까지 ‘채택’하지 않는다.
2. 장르 표면(재벌, 명품, 특정 직업)은 구조 원리로 취급하지 않는다.
3. 독자 체감 보상, 회차 훅, 상태 변화를 수치와 근거 위치로 기록한다.
4. 추출한 원리는 InkOS 기획서와 Arc의 빈칸을 더 잘 채우는 경우에만 `inkos_handoffs/`로 승격한다.
