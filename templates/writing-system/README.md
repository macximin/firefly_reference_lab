# 웹소설 집필 시스템 P0~P8 계약팩

이 폴더는 실제 원고를 쓰기 직전까지 필요한 최소 계약을 보관한다. 템플릿을 모두 길게 채우는 것이 목적이 아니다. 주인공의 이득, 독자 약속, 지급할 보상, 작품 표면을 놓치지 않고 다음 원고로 넘기는 것이 목적이다.

## 권위 순서

1. 사용자 의도와 작품 캐논
2. `docs/2026-08-15-male-webnovel-commercial-editorial-principles.md`
3. `01-series-contract.md`
4. 현재 `03-narrative-arc-v2.md`
5. 현재 `04-chapter-packet.md`
6. 선택한 `08-gold-router.md`의 역할별 조언
7. 일반 장르 지식과 커뮤니티 팁

아래 단계의 문서가 위 단계의 약속을 바꾸지 못한다. 충돌하면 평균을 내지 않고 상위 권위로 돌아간다.

## 완료 게이트

- 빈 필수 항목이 없다.
- 주인공 자신의 이득이 모든 목표와 선행보다 먼저 설명된다.
- HOW는 설명이 아니라 실제 사용 장면으로 약속된다.
- 보상에는 독자가 볼 수 있는 장면 영수증이 있다.
- 필수 정보·단서·비밀·정보 누락을 구분한다.
- Arc 길이를 먼저 정하지 않는다.
- 조연·외부 시점이 주인공의 이득·위협·인정으로 돌아온다.
- 골드는 사건·인물·문장 복제가 아니라 판단 역할로만 사용한다.
- P9에 들어가기 전 첫 3개 NarrativeArc와 첫 1~3화 Chapter Packet이 준비된다.
