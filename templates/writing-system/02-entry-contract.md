# Entry Contract

초반 회차 수를 먼저 정하지 않는다. 아래 기능이 실제 장면으로 모두 지급되는 최소 구간을 Entry 구간으로 본다.

## 진입 약속

- 독자가 이입할 주인공의 구체적 결핍·모욕·욕망:
- 주인공이 가장 먼저 챙길 자기 이득:
- 작품의 장르와 반복 보상을 보여주는 장면:
- HOW를 한눈에 이해시키는 첫 사용:
- HOW가 주인공에게 유일하다는 증거:
- 첫 승리·획득·인정:
- 첫 지급의 목격자와 반응:
- 다음 결제를 부르는 구체적 질문:

## 기능 순서

| 순서 | 기능 | 구체 장면 | 회차 | 지급 확인 |
| --- | --- | --- | --- | --- |
| 1 | 주인공 이입 |  |  |  |
| 2 | 자기 이득과 목표 |  |  |  |
| 3 | 장르 보상 약속 |  |  |  |
| 4 | HOW 실행 |  |  |  |
| 5 | 첫 보상 영수증 |  |  |  |
| 6 | 다음 질문 |  |  |  |

## 초반 주인공 중력

- 조연 소개가 주인공에게 돌아오는 방식:
- 세계관 설명이 주인공의 욕망·보상과 연결되는 방식:
- 주인공 없는 장면이 있다면 반드시 필요한 이유:
- 삭제하거나 뒤로 미룰 독립 조연 서사:

## 합격 기준

- 주인공의 얼굴과 욕망보다 세계관 명사가 먼저 쌓이지 않는다.
- 특별함을 말로만 설명하지 않고 주인공이 써먹는다.
- 첫 지급을 유료 전환 뒤로 숨기지 않는다.
- 1~3화라는 숫자를 맞추기 위해 장면을 압축하거나 분할하지 않는다.
