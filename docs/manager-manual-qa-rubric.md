# 15작품 Arc 분석 관리자 수동 QA

자동 검증 통과는 완료의 필요조건이지 충분조건이 아니다. 작품별 기본 세션이 완료를 선언하면 아래 순서로 검수하고, 실패 시 새 세션이 아니라 같은 thread를 `gpt-5.6-sol`·`ultra`·Fast로 재개한다.

## 선행 게이트

```bash
node tools/validate-five-work-analyses.mjs <work-slug> --strict
```

오류나 경고가 하나라도 있으면 수동 QA 전에 완료를 거부한다.

## 관리자 고정 표본

1. 전체 회차를 초반 1~33%, 중반 34~66%, 후반 67~100%로 나눈다.
2. Arc가 8개 이하면 전 Arc를 보고, 9개 이상이면 각 구간의 첫·중앙·끝 Arc를 골라 최대 9개를 본다. 첫 Arc와 결말 Arc는 반드시 포함한다.
3. 선정 Arc마다 첫 화·중간 화·결산/끝 화·다음 Arc 첫 화를 원문과 대조한다.
4. 중복되지 않는 최고 보상 2화·최고 훅 2화·주요 관계 변화 2화를 추가한다.
5. 원문 → `chapter_map.csv` → `arc_pacing.csv` → `arc_map.csv` → `arc_atlas.md` → `project_bible.md`를 한 줄로 추적한다.
6. 같은 결함이 서로 다른 두 구간에서 나오면 국소 수정이 아니라 시스템성 실패로 승격한다.

## 15개 검사항목

1. **원문 사실 충실도**: 실제 인물·장소·물건·사건 순서·승패·금액·기록·지급 결과가 맞는가.
2. **작품 표면 밀도**: 이름 없는 기능어가 아니라 고유명사와 구체 행동이 분석어보다 먼저 나오는가.
3. **기획서 독립 완결성**: 기획서만 읽어도 출발·욕망·능력·관계·초중후 사건·대표 보상·결말을 따라갈 수 있는가.
4. **회차 Loop 구체성**: 진입·약속·목표·행동·저항·전환·보상·변화·훅이 같은 사건의 말 바꾸기가 아닌가.
5. **Arc 경계 정당성**: 실제 경계 신호가 두 개 이상이며 전후의 지배 목표·상대/장소·결산·열린 루프·비가역 상태가 달라지는가.
6. **Arc 고유성과 자연 길이**: 고정 길이 분할 흔적 없이 사건형 이름·과제·상대·결산에 따라 길이가 달라지는가.
7. **Arc 내부 드라마**: 도입→약속→전진→압박→전환→구체 결산→여진/다음 훅이 실제 회차 비트로 확인되는가.
8. **긴장·보상·훅 점수 근거**: 장면 체감과 점수가 맞고, 같은 공식 곡선을 여러 Arc에 복제하지 않았는가.
9. **페이싱 리본**: 정보·행동·관계·감정·물질/지위 비중이 실제로 달라지고, 머묾/압축 판단이 재미 기준인가.
10. **약속과 지급**: 지금 지급한 소보상·큰 결산·유예한 독자 부채·잔여 비용이 구체적으로 갈리는가.
11. **관계·지위·능력 영수증**: 호칭·자리·식사·목격자 반응·선택·계약·직책·기록 같은 관찰 가능한 전후 증거가 있는가.
12. **훅과 루프 연속성**: 훅이 구체적인 다음 압력을 열고, 열린 루프가 다음 회차/Arc에서 이어지거나 결산되는가.
13. **초중후 성장 곡선**: 핵심 독자 계약을 유지하면서 목표 규모·보상 통화·관계 폭·세계 범위·페이싱이 갱신되는가.
14. **파일 간 의미 정합성**: 사건·범위·Arc 이름·지급·관계 변화·결말이 모든 파일과 완료 영수증에서 일치하는가.
15. **비기계적 편집 품질**: 실제 사건을 읽은 편집자의 판단이며 과잉 분류·템플릿 문장·현실 고증·미세 오류 집착이 중심이 아닌가.

## 실패와 재작업

- 핵심 사건·결말·보상 창작 또는 뒤바꿈 1건은 즉시 실패다.
- 표본의 15~20% 이상에서 범용 문구·필드 말 바꾸기·공식 점수·이름 없는 분석이 보이면 시스템성 실패다.
- 서로 다른 두 시기에서 같은 결함이 나오면 영향 파일 전체를 다시 만든다.
- Arc 경계를 바꾸면 인접 Arc와 해당 범위의 ID·회차 지도·페이싱·아틀라스를 모두 다시 검증한다.
- 시스템성 실패 뒤에는 기존 표본 외에 초·중·후 Arc를 하나씩 더 뽑아 재발 여부를 본다.

`strict` 통과, 15개 항목 통과, 미확정 사항의 정직한 `completion_receipt.md` 기록이 모두 갖춰져야 한 작품을 승인한다.
